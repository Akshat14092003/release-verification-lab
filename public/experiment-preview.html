Correct behaviour

Lets an existing account sign in with the wrong password. Unknown emails also get a new session.

How to try it 5 matching checks
  1. Sign out and open the customer sign-in page.
  2. Choose the demo Customer and enter a wrong password.
  3. Try signing in. Correct behaviour rejects the credentials.

Correct behaviour

Removes the weekend-only check, so the promotional offer can be bought on a weekday.

How to try it 5 matching checks
  1. Set the demo day to Monday.
  2. Open Offers and try adding the weekend deal to your cart.
  3. Correct behaviour rejects the purchase without writing an order.

Detected by: API · Browser · Database

Correct behaviour

Lets a direct purchase request buy the same offer again after its one-purchase limit. The normal button still blocks repeats.

How to try it 1 matching check
  1. Buy the weekend offer once through checkout.
  2. On Offers, use Send direct repeat purchase.
  3. Correct behaviour rejects the repeat request.

How to try it 1 matching check
  1. Add two different products and complete checkout.
  2. Compare the receipt total with Transactions.
  3. Correct behaviour shows the same total in both places.
